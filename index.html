Lidhit Widget — smoke test (GH#788)

Виджет — кнопка в правом нижнем углу. Сценарий: открыть чат → написать сообщение → оставить телефон. Каждое событие попадёт в console.log (DevTools → Console, префикс [lidhit]) и в лог ниже.

  1. open — посетитель открыл окно чата
  2. conversation_started — начался диалог (первое сообщение)
  3. qualification_completed — квалификация завершена, получены контактные данные

lead_captured — прежнее имя того же события, оно продолжает приходить как deprecated-алиас (одновременно с qualification_completed, с тем же payload). Для новых интеграций используйте qualification_completed.

По умолчанию страница грузит продовый loader.js. Чтобы проверить сборку из PR-превью, добавьте &loader=https://pr-123.lidhit.com/widget/v1/loader.js — разрешены только адреса на lidhit.com и его поддоменах.
